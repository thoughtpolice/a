# Static GCC 4.7.4 C++ libraries

BUILD declares 123 C++ translation units and the C ABI demangler, their
per-source language/template settings, and deterministic `libstdc++.a` and
`libsupc++.a` archives. The newly built GCC 4.7 compiler builds these target
libraries. All sources and headers come from the pinned GCC archive; the
configuration and gthread headers are generated by bootstrapped sed and catm.
No configure or Make process runs. The explicit header installation includes
standard C++98/C++11 headers, TR1/TR2, GNU extensions, debug and profile modes.
OpenMP parallel mode remains outside this native C/C++ target.

The reviewed LP64 musl configuration uses generic locale and stdio support,
POSIX threads, native atomics and TLS. It uses ordinary 64-bit file APIs;
`_GLIBCXX_USE_LFS` would select the obsolete *64 aliases absent from musl 1.2.5.
The pinned reference's strong pthread-reference adaptation preserves threading
in static links. Generic locale support provides C/POSIX locales and custom
C++ facets; it does not promise installed named system locales. Upstream GCC
4.7's C++11 implementation remains the compatibility level of this library.

Twelve tests run at both `-O0` and `-O2` across six programs: cross-translation-
unit exceptions, cleanup, nested exceptions and exception pointers; RTTI and
demangling; C++98 containers and GNU policy-based trees; C++11 ownership,
unordered containers, functions, random numbers and arithmetic; concurrent
threads, condition variables, futures, call_once and local static initialization;
and narrow/wide streams, custom locale facets and sparse-file seeks past 2 GiB.
The standalone ABI program suppresses default libraries and links libsupc++,
libgcc and musl explicitly, checking global destructor order as well.

```
buck2 test cellar//bootstrap/stage1/libstdcxx: --local-only -j 8
buck2 build cellar//bootstrap/stage1/libstdcxx:stage1-installation
buck2 run cellar//bootstrap/stage1/libstdcxx:stage1-g++ -- --version
```

The compiler command preserves declared headers, runtimes and native tools
through RunInfo. The installation target explicitly maps headers, libraries
and upstream license files. All three GCC stages instantiate the same graph.

At `242da897`, all twelve C++ tests passed in both workspaces, alongside
three tar tests in the relocated run. All 619 installed files matched across
absolute workspace paths. The closure audit reported 12518 targets and 13058
actions without violations; incremental process tracing covered 2904 bootstrap
processes and 468891 open calls without boundary violations. All twelve test
programs are static ELF executables. This evidence covers the first C++ runtime
stage; later-stage object comparison is a separate acceptance gate.

The stage2/stage3 gate compares all 124 C++ library objects and both archives
byte-for-byte. All twelve execution tests pass for each of the three stages;
`stage3-g++` is the final compiler command. These checks are included in the
combined 998-test GCC/C++ gate.
