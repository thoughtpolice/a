# The framework types the gameplay CoreLib declares (see
# corelib/generator/Program.cs): what gameplay code compiled against .NET's
# reference assemblies can name. `namespace N` keeps N's top-level types,
# `type N.T` one type, `exclude N.T` leaves one out; nested types follow
# their containing type. A type CoreLib's own sources define (runtime/*.cs,
# corelib/*.cs) is theirs, whatever this says. A kept type's members that
# name a type left out are dropped with it.
