How this example works

C# runs the physics and collisions inside WebAssembly. It allocates a fresh array of body objects each tick and calls typed imports to queue changes. JavaScript owns the world, commits successful ticks, and draws the result.

“Test rollback” deliberately queues a movement and then traps. The host discards that tick, preserving the world. Resume to continue with the same instance.
