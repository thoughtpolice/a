# Allowlist for culling the nginx packages down to just the nginx
# binary (plus its .so closure, resolved automatically) and the one
# upstream config file we reuse verbatim: mime.types.
#
# Everything else nginx needs — our nginx.conf, the systemd unit, the
# index.html, and any runtime directories — comes from the nginx overlay
# layer (the :nginx-overlay-layer target in BUILD).

# /usr/lib/nginx module tree to carry.
/usr/bin/nginx

# mime.types is large and annoying to hand-ship; grab Wolfi's copy.
/etc/nginx/mime.types
